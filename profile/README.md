The _Open Source Networking Configuration Labs_ projects contain a series of configuration exercises that will help you master the intricacies of:

* [Border Gateway Protocol](https://bgplabs.net/), the (routing) glue that holds the Internet together
* [IS-IS](https://isis.bgplabs.net/), an interesting alternative to OSPF.
* [VXLAN and EVPN](https://evpn.bgplabs.net/), a modern way to build overlay L2VPN and L3VPN services.

You can run the labs on virtual network devices (recommended), including in free GitHub Codespaces, or on physical gear, and use them with almost two dozen platforms from a dozen different networking vendors.
